# Shagun brand kit

Adapted from the existing Leash website at the user's request. Preserve this system as the UI expands.

- Typography: Urbanist for headings and interface text; Geist Mono for labels, amounts, and receipts.
- Surfaces: off-white `#fafafa`, ink `#262626`, rules `#e5e5e5`, muted text `#595959`.
- Primary action: existing blue `#193ef9`, with off-white text.
- Illustration blocks: existing pink `#ffbfec`, green `#36d972`, orange `#ff942e`, lavender `#a199ff`. Use dark ink on these blocks. Use green ink `#006023` for success text.
- Layout: thin grid rules, boxed mono section tags, generous whitespace, oversized tight-tracked headings, square buttons and panels. Use a quieter compact grid for the dashboard.
- Visual motif: geometric gift envelopes and a circular seal. Build these with CSS/SVG in the existing illustration language.
- Motion: short entrances and control feedback; no continuous motion. Respect reduced-motion preferences. Content must remain visible without JavaScript animation.
- Voice: direct and warm. Explain what happens to a gift. Label indicative rates and RazorpayX test payouts honestly. Never suggest a simulated payout is actual cash received.
- Theme: the existing light theme is the product default. Colors are tokenized; a dark theme is outside this first build.
